# Laboration 1 | Programmering i TypeScript
I denna laboration så har vi fått öva på grunderna i TypeScript. Vi har fått utveckla en applikation som gör det möjligt för användaren att lägga till 
kurser via ett formulär. Dessa kurser ska sedan skrivas ut i en lista så att man kan se sina sparade kurser. Med hjälp av localStorage så sparas de kurser man 
har lagt till även om sidan skulle laddas om eller om webbläsaren skulle startas om. Det finns möjlighet att lägga till kurser, se kurser och radera kurser.
